# S.H.I.E.L.D

SHIELD stands for `Systematic Hierarchical Integration and Evaluation Layer for Defense`.

It aims to be an integrated platform for ensuring programmed systems are operating as they should across multiple horizons and layers of analysis.

Most notably, it is focused on *accuracy* in the form of *tests* and *performance* in the form of *benchmarks*. And of course, oneshot results are not worth a lot. SHIELD integrates **regression** detection by storing results in a database. This is an opt-in behaviour.

## Design Philosophy

The idea behind SHIELD is to provide a unified framework to defend one's systems built on my own infrastructure. It intends to be minimal-overhead by adhering to Data Oriented Design instead of Object Oriented Design.

Eventually the aim for SHIELD is to integrate directly with the upcoming *LOUPE* engine and be able to be used across languages through loupe. For now, however, it is tied to my Go ecosystem.
